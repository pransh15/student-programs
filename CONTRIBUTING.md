# Contributing

Thanks for helping keep this list useful.

## Add a program

Please open a PR that updates `README.md` with one new entry in the most relevant category.

Use this format:

```md
- [Program Name](https://official-link.example.com) - One clear sentence describing who the program is for.
  > Optional note on eligibility, benefits, region, or application status.
```

## What qualifies

A program should be one of these:

- Free credits, tools, or licenses for students (cloud, dev tools, design, IDEs, etc.)
- Paid or unpaid fellowships, internships, or mentorships aimed at students
- Campus or student ambassador programs for technical/creator tools

## Requirements

Before submitting:

- Use the **official program page** whenever possible.
- Put the entry under the best matching category.
- Keep descriptions short and factual.
- Do not add affiliate links, referral links, or tracking links.
- Do not add generic communities unless there is a clear student benefit or ambassador path.

## Good PR checklist

- [ ] Program link works
- [ ] Entry uses the list format
- [ ] Category is appropriate
- [ ] Description explains who it is best for
- [ ] No duplicate entry already exists

## Suggest without a PR

If you do not want to open a PR, create an issue with:

- Program name
- Official link
- Category you think it belongs in
- One-line description
- Notes on eligibility, benefits, or application status
